Description:
Peanut Client App is a simple Android application built using Java and XML in Android Studio.
It demonstrates basic app structure and user flow, including login, profile, and trades list screens.
The project uses Retrofit for networking setup and RecyclerView for displaying trade data.

Features:

User login and logout

Profile details display

Trades list using RecyclerView

Simple, clean UI following Android design principles

Tools & Technologies:
Java • Android Studio • XML • Retrofit • RecyclerView
